# Privacy data map, SDK и сетевые запросы

Состояние на версию 1.0 (1). Документ описывает фактическое поведение кода; при добавлении SDK или сервера его
нужно обновить вместе с App Privacy в App Store Connect и `PrivacyInfo.xcprivacy`.

## Принципы

- Нет регистрации, аккаунта, собственного сервера, рекламы и трекинга (`NSPrivacyTracking = false`).
- Все проекты, фото, отчёты и копии хранятся только на устройстве пользователя.
- Приложение ничего не отправляет само: файлы уходят только через системные Share / Files / Mail / Photos
  по явному действию пользователя.
- Аналитика: подготовлен типизированный адаптер, провайдер **не подключён**, сбор выключен
  (`LocalAnalyticsService.isCollectionConfigured = false`); в Debug события пишутся только в локальный журнал.

## Что хранится на устройстве

| Данные | Где | Когда появляется | Как удалить |
|---|---|---|---|
| Проекты: название, объект/адрес, клиент, заметка, дата работы | SwiftData, `Application Support/WorkPhotos/Database` | пользователь вводит | удалить проект; «Удалить все данные» |
| Оригиналы фото | `Application Support/WorkPhotos/Originals` | съёмка или импорт | удалить фото/проект; «Удалить все данные» |
| Метаданные фото: дата/время и смещение, источник даты, подпись, роль до/после, размеры, SHA-256 | SwiftData | съёмка/импорт/редактирование | вместе с фото |
| Место кадра: координаты, точность, тип разрешения, адрес от геокодера, ручной адрес | SwiftData (поле фото) | только если пользователь включил геоданные или ввёл адрес | убрать ручной адрес у фото; не публиковать — экспорт «без места» и переключатели PDF (выключены по умолчанию); удалить фото; «Удалить все данные». Отдельной команды «стереть GPS у сохранённого кадра» в v1 нет |
| EXIF импортированных файлов (в т. ч. GPS, если был в файле) | внутри оригинала (байты не меняются) | импорт | вместе с фото; при экспорте «без места» GPS удаляется из копии |
| Готовые PDF и snapshot настроек отчёта | `Application Support/WorkPhotos/Reports/<id>` | генерация отчёта | удалить отчёт; удалить фото с выбором «удалить отчёты»; «Удалить все данные» |
| Профиль исполнителя, логотип, брендовые пресеты | SwiftData, `Logos/` | пользователь вводит | очистить в настройках; «Удалить все данные» |
| Настройки (штамп по умолчанию, язык/формат отчёта, выбранный Free-проект) | SwiftData `AppPreferences` | использование | «Удалить все данные» |
| Флаги «онбординг пройден», «лимиты импорта показаны», выбранный язык приложения | UserDefaults | использование | удаление приложения |
| Счётчик бесплатного лимита: сколько фото добавлено и проектов создано (два числа, без идентификаторов) | Keychain приложения, не синхронизируется | съёмка, импорт, создание проекта | намеренно не удаляется ни «Удалить все данные», ни переустановкой (решение владельца: квота Free на всё время) |
| Миниатюры | `Caches` (восстанавливаются) | просмотр | «Очистить кэш» |
| Кэш адресов геокодера | только память процесса, до 200 записей | получение адреса | закрытие приложения; «Удалить все данные» |
| Коды последних ошибок (до 10, без текста и данных) | только память процесса | ошибки | «Удалить все данные»; закрытие приложения |
| Временные файлы экспорта/импорта/копий | `tmp`, staging | операции | очищаются при запуске и после операций |

Снятые камерой оригиналы не содержат GPS в EXIF: место хранится отдельно в базе и попадает в штамп, PDF или
EXIF экспортируемого файла только если пользователь это выбрал.

Резервная копия (ZIP) содержит оригиналы, метаданные (включая места и данные клиентов), отчёты и логотипы; пароля
в v1 нет — пользователь предупреждается перед созданием. Состояние подписки в архив не попадает.

## Сетевые запросы

| Запрос | Кто выполняет | Какие данные уходят | Когда |
|---|---|---|---|
| Reverse geocoding (адрес по координатам) | Apple, `CLGeocoder` через `ReverseGeocodingService` | координаты кадра и язык | только при включённых пользователем геоданных; не чаще 1 запроса в 1,2 с; повтор только по сохранённым координатам |
| StoreKit 2: продукты, покупка, статус подписки, Restore | Apple, StoreKit | данные Apple Account обрабатывает Apple; приложение не передаёт свои данные | открытие paywall/подписки, покупка, явное «Restore Purchases» |
| Ссылки политики, условий, формы поддержки | Safari / системные экраны | только URL без параметров, без данных пользователя | по нажатию пользователя |
| Письмо в поддержку | системная почта (MessageUI или mailto) | текст пользователя; диагностика — только если включена и показана заранее; вложение — по выбору, перекодировано без метаданных | по нажатию «Write email» |

Других сетевых вызовов нет: в коде приложения нет `URLSession`, сокетов, WebView, push-уведомлений и сторонних
сетевых SDK.

## Разрешения

| Разрешение | Ключ Info.plist | Когда запрашивается | Без него |
|---|---|---|---|
| Камера | `NSCameraUsageDescription` | первый вход на вкладку камеры (не в онбординге) | импорт и проекты работают, есть переход в Settings |
| Геолокация «при использовании» | `NSLocationWhenInUseUsageDescription` | только после явного включения геоданных в камере | фото без места, PDF формируется |
| Добавление в Фото (add-only) | `NSPhotoLibraryAddUsageDescription` | первое «Save to Photos» | Share и Files работают |

Фоновой геолокации, доступа к контактам, микрофону, всей фототеке (импорт — через `PhotosPicker` без разрешения),
трекинга (ATT) нет.

## Диагностика поддержки

Отправляется только при включённом переключателе и видна до отправки: версия и сборка приложения, версия iOS,
модель устройства, язык, тема обращения, до 10 технических кодов ошибок, диапазон свободного места. Без фото, адресов,
GPS, названий проектов, имён клиентов и текста пользователя (проверяется `testDiagnosticsContainNoUserContent`).

## SDK и зависимости

| Компонент | Версия | Лицензия | Назначение | Сеть | Сбор данных |
|---|---|---|---|---|---|
| ZIPFoundation | 0.9.20 (exact) | MIT | ZIP для резервных копий и пакетного экспорта | нет | нет |

Остальное — системные фреймворки Apple: SwiftUI, SwiftData, AVFoundation, PhotosUI, Photos (add-only), CoreLocation,
ImageIO, CoreText, PDFKit, StoreKit, MessageUI. Firebase и другие аналитические/рекламные SDK не подключены.

## Privacy manifest (`PrivacyInfo.xcprivacy`)

- `NSPrivacyTracking`: false, `NSPrivacyTrackingDomains`: пусто, `NSPrivacyCollectedDataTypes`: пусто.
- Required reason API: UserDefaults — `CA92.1` (настройки самого приложения); DiskSpace — `E174.1` (проверка места
  перед записью), `85F4.1` (показ свободного места пользователю).

## Предлагаемые ответы App Privacy в App Store Connect

«Data Not Collected»: разработчик не получает данные пользователя — всё хранится на устройстве, сервера нет,
аналитика выключена. Координаты, которые Apple использует для геокодирования, обрабатывает Apple как платформа.
Письмо в поддержку пользователь отправляет сам из своей почты; если владелец будет хранить такие письма, нужно
оценить, требует ли это раскрытия «Contact Info / Customer Support» по правилам Apple на момент публикации.

Ответы в App Store Connect — решение владельца приложения; при подключении аналитики, крэш-репортинга или сервера
их нужно пересмотреть.
